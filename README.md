# UpNext

UpNext provides health programs focused on behavior change, prevention, and participant data.

The Diabetes Prevention Program is available at [upnextcare.com/dpp](https://upnextcare.com/dpp/).

## Design system

The canonical UpNext Care design system is maintained in [design-system/](design-system/README.txt), alongside this site's source code. Open [the visual reference](design-system/index.html) to explore the palette, typography, components and usage examples.

- Shared CSS: `design-system/upnext.css`
- Portable tokens: `design-system/tokens.json`
- HTML starter: `design-system/components.html`
- Regenerate the reference and download kit: `python3 design-system/build.py`

The shared visual identity is applied to all 36 HTML entrypoints, including public pages and participant screens, through `design-system/site-theme.css`. Existing content and application scripts are preserved. The showcase JavaScript is for demonstrations only.
